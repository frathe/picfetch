# Domain Docs

This repository uses a single-context domain-documentation layout.

## Before exploring

Read these files when they exist and are relevant:

- `CONTEXT.md` at the repository root
- ADRs under `docs/adr/`

If they do not exist, proceed silently. Domain-modeling workflows create them
when terminology or architectural decisions need to be recorded.

## Vocabulary

Use terminology defined in `CONTEXT.md` consistently. If a required concept is
missing, reconsider whether new terminology is necessary or record the gap for
domain modeling.

## Architectural decisions

Surface any conflict with an existing ADR explicitly instead of silently
overriding it.
