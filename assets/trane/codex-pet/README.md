# Trane

A warm, curious golden retriever with honey-gold fur, a cream muzzle and chest, floppy ears, expressive brown eyes, a red collar, and a plain round gold tag. Gently cartooned with believable canine proportions and softly defined fur.

Generated with the built-in imagegen tool, grounded in the supplied Trane illustrations. Canonical base art holds the identity consistent through the animation set.

Prompt set: calm breathing/blinking idle; alternating four-legged trots to the right and left; seated paw wave; small hop; sad/deflated reaction; expectant asking pose; seated focused paw movements for active work; careful visual inspection; and a continuous 16-direction gaze sequence. Looking turns the head and eyes around an anchored seated body, with naturally following ears. No extra props, scenery, text, shadows, or detached effects.

The hatch-pet v2 format contains nine standard animation rows and 16 clockwise looking directions. The final spritesheet uses 192x208 cells in an 8x11 grid and is paired with a version 2 pet manifest.
