## Findings against immutable head

All three are P2; no P0/P1 established by this axis. No separately established scope-creep finding.

F1 — Case aliases bypass transaction ownership and current-file reconciliation. On case-insensitive APFS (Windows exposure was not demonstrated by this reviewer), save `photo.jpg` and export to `PHOTO.jpg`: both encode/replace without sharing a turn; successful export can leave rotation/reset state stale. `internal/imaging/mutations.go:39`, `internal/ui/filework.go:98`. Issue23:15: “Serialize conflicting operations across their complete read-transform-write transaction using the resolved source identity”; issue23:19: “Refresh/invalidate the appropriate caches and current metadata/info once after success”. Lead's native reds recorded in `case-repro.log` (TestReviewCaseAliasTransactions and TestReviewCaseAliasExport); independently assessed against spec, not redundantly reproduced here.

F2 — Save Changes can resurrect a successfully trashed source. Pause Save's encoder, confirm Trash for the same file, allow the OS move to finish, then let Save finish: atomic rename recreates the source while deletion delivery removes it from the viewer and reports success. `internal/ui/deletion/deletion.go:252`; issue23:16: “Ensure existing write routes participate when they can target that same resolved file”; MA AC04:205: “Every successful deletion is reconciled by identity”. New deterministic real-writer/temporary-trash red: `TestSpecReviewSaveThenTrashDoesNotResurrect`, overlay `spec-overlap-overlay.json`; observed `stat=<nil>` after successful Trash. Production fix assigned after review completion, tracked separately.

F3 — A cancelled startup scan/sort leaves --slideshow armed. Cancel the launch operation or use Close Files, then drop unrelated files: pendingPictureFrame starts slideshow. `internal/ui/launchoptions.go:109–118`, cancellation routes `drop.go`/`sort.go`/`viewer.go`. Launch AC6:84–85: “--slideshow enters picture-frame mode after the launch file set loads, and exactly once - a later drop does not re-enter it.” Lead supplied deterministic overlay `/private/tmp/picfetch-release-spec/launch-overlay.json`; independently confirmed stale flag control flow.
