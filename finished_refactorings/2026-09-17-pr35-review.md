# PR #35 review and verification

Route: Standard. Lead owns review and fixes. Final scope: reject Save Changes
through symlink leaves while preserving ordinary saves and parent-directory
aliases. No new dependencies, UI strings, packages, or merge/release actions.

## Final contract and acceptance criteria

1. Save Changes rejects existing symlink leaves, including dangling links, before
   reading metadata or writing. Both link and target remain unchanged; failure
   never reports a committed write. Encoder availability uses the selected name.
   `go test -tags no_emoji,nodynamic ./internal/imaging -run 'Test(CanEncode|SaveRotated|FileWritesPreserveSymlinkParentsAndRejectSymlinkLeaves)' -count=1`
2. Save/Strip/Export retain transaction serialization, cancellation and commit
   identity. Save and Export support parent-directory aliases while rejecting leaf
   symlinks; Strip retains its existing target-following semantics.
   `go test -tags no_emoji,nodynamic ./internal/imaging -count=1`
3. Viewer save/export state and reconciliation remain correct.
   `go test -tags no_emoji,nodynamic ./internal/ui -run 'Test(CanSaveRotation|SaveRotation|SaveChanges|Export)' -count=1`
4. `make fmt-check vet build`, GoLand inspections of every changed Go file, and
   latest-head hosted CI/Codex code/security/Qodana/CodeQL must pass before handoff.

## Implementation and review dispositions

- Save uses the existing Export destination policy: resolve parent directories,
  reject a leaf symlink, and keep the selected leaf unresolved for atomic rename.
  The shared path error now uses the operation-neutral `write` label.
- Tests cover live/dangling symlink refusal with no committed result, unchanged
  links/targets, selected-name encoder selection and serialized directory aliases.
  The refusal test was observed failing before the fix.
- The initial replacement policy had a queued Save/Strip ordering defect. The first
  local fix revalidated destinations after admission; its regression failed before
  the fix and passed afterward. Qodana's defer-in-loop warning was confirmed false
  and narrowly suppressed in that intermediate implementation.
- Codex security then identified that replacing a symlink could copy target pixels
  and JPEG metadata into a directory with broader access. The finding was accepted;
  refusal replaces the original policy. Since a successful Save can no longer
  replace an existing symlink, the earlier retry logic/test and its suppression
  are unnecessary and were removed. The final transaction implementation remains
  the established one. No source suppression is needed in the final change.

## Limits

Save Changes refuses leaf symlinks through the existing error path; users can
explicitly Export to a regular destination. Parent-directory symlinks remain
supported. This change does not provide filesystem-wide exclusion against other
processes or pin mutable parent directories.
