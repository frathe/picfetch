## Finding and decision

The new erasure accepts a missing thumbnail offset as zero and can erase the
TIFF header. More generally, an in-bounds range alone does not establish that
it contains a JPEG thumbnail. Require an unambiguous offset/length pair and a
complete JPEG occupying that range before clearing it. Malformed thumbnail
descriptors retain the existing conservative behavior: unlink IFD1 without
guessing which bytes to erase. This is not a general metadata privacy scrubber;
explicit metadata stripping remains the operation that removes all EXIF.
