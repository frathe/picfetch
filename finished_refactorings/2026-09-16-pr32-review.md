## Findings and decisions

- Native Windows CI fails three updater tests: two fixtures lack authenticated
  provenance, and the retained-handle test assumes Unix rename semantics.
- The archive and extracted-file digest must originate from the verified memory
  buffer. Filesystem contents cannot establish authenticated payload identity.
- Windows must hold a read handle that denies writes until installation finishes.
- The authenticated install must use the same rollback implementation exercised
  by the existing failure/retry/relaunch tests.
- Preserve process-local seals and the intentional redownload after restart.
- No dependency changes. Existing x/sys Windows bindings retain their current
  source, license and distribution obligations.
