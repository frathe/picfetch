## Agent skills

### Issue tracker

Issues and specs are tracked as local Markdown under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The default canonical triage-label vocabulary is used. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context domain-documentation layout. See `docs/agents/domain.md`.

### Branch safety

Keep any branch whose name contains `website` or `webpage` (case-insensitive) separate from `main`; publish it independently and never merge it into `main`.
